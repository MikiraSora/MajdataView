SlideDrop 变速（Soflan）实现方案

视觉吃变速 · 判定锚真实时间 · 竖式图表实现文档

〇、核心原则

soflan = 纯视觉 判定 / 计分 / DJAuto触发 / 销毁 = 真实时间 HideBar 击杀 = 永久

整个方案建立在一条铁律上：soflan 只改"星星画在哪、轨道多亮"，一切决定判定、计分、销毁的判断都读真实时间。二者在代码里彻底解耦，互不污染。

soflan 函数统一为：soflan(x) = SoflanManager.Instance.ConvertAudioTimeToY_PreviewMode(x, soflanGroup)，带帧内缓存（同帧同组只算一次）。返回值在 soflan-Y 空间（速度对时间的积分，量纲 ≈ ms）。

一、进度模型：单一全局进度轴

// 端点（真实时间锚点）
beginTime = timeStart + fadeInTime
endTime   = time + LastFor

// 每帧只算一次 soflan(audioTime)，与预计算锚点相减
currentSoflanProgress = normalize(
    (soflan(audioTime) − soflan(beginTime))
  / (soflan(endTime)  − soflan(beginTime))   // 分母用 soflan-Y 跨度 → 量纲 Y÷Y，恒在 [0,1]
)
量纲修正：原始设想分母是 endTime − beginTime（真实秒），与分子的 soflan-Y 空间量纲不匹配。改用 soflan(endTime) − soflan(beginTime) 后分子分母同为 Y 空间，进度天然归一。

normalize：分段钳制（进度冲出 [0,1] 的处理）

二、可见性 = 两层叠加

每根箭头（及星星）的最终可见性由两个来源合成，规则：被 HideBar 击杀的永久为 0，否则取 soflan alpha。killed 赢。

soflan alpha 层（appearance）

整条轨道 + 星星统一淡入窗口 alpha，随进度可逆，能反复显/隐（振荡）。逐根 alpha 只是实现手段，空间上仍整条统一。

仅作用于 i > maxHiddenIndex（未被击杀）的 bar。
HideBar 层（判定 / AutoPlay）

判定推进 / 自动演示驱动，逐根永久击杀，最高优先级。带单调保护：只增不减，soflan 怎么倒退都不会把已击杀的箭头点回来。

对应最初铁律"被 hideBar 处理过就不再重新显示"。
void HideBar(int endIndex):
    endIndex = min(endIndex − 1, slideBars.Count − 1)
    if (endIndex <= maxHiddenIndex) return          // 单调保护
    for i in (maxHiddenIndex+1 .. endIndex): slideBars[i].SetActive(false)
    maxHiddenIndex = endIndex

三、视觉 / 逻辑解耦（最关键的一刀）

star_slide.transform.position 原本一物两用：既渲染星星，又被 DJAuto 的 Running() 读去触发 Sensor。soflan 一动，DJAuto 就会在错误时刻点 Sensor，判定漂移。必须拆开。

视觉侧 · 吃 soflan

  • 星星位置 / 朝向 / scale
  • 轨道 alpha
  • 星星显隐

驱动量：currentSoflanProgress（可逆）

逻辑侧 · 锚真实时间

  • DJAuto Running() 触发 Sensor（用独立 logicStarPos）
  • Enable/Random 的 DestroySelf / judgeQueue.Skip
  • 自动演示 HideBar

驱动量：真实时间 process = (AudioTime−time)/LastFor

落地方式：UpdateStar() 一分为二 —— UpdateStarVisual(process) 只做位置/朝向/alpha（soflan 路与真实路各喂各的 process）；UpdateStarLogic() 恒用真实时间 process 处理销毁/跳队列。Running() 不再读 transform，改读真实时间算出的 GetLogicStarPos()。

四、实现步骤（改哪些方法 / 加哪些字段）

1

接线 JsonDataLoader.cs · InstantiateStar()

在赋 NDCompo.soflanTime 那段旁补 SliCompo.soflanGroup = timing.SoflanGroup;。Wifi 分支不动。soflan 锚点不用单一 soflanTime，由 SlideDrop 自己预计算。

2

新增字段 SlideDrop.cs

float soflanBegin, soflanTimeStart, soflanMoveStart, soflanEnd;  // soflan-Y 锚点
float beginTime;              // = timeStart + fadeInTime
bool  soflanEnabled;
int   maxHiddenIndex = −1;    // HideBar 单调保护
3

锚点预计算 Initialize() 末尾

beginTime = timeStart + fadeInTime；soflanEnabled = containsSoflans()；若启用则一次性算好 soflanBegin / soflanTimeStart / soflanMoveStart / soflanEnd（用带缓存的 GetSoflanValue）。每帧只需再算一次 soflan(audioTime)。

4

Update() 拆双路 Q11

开头 if (soflanEnabled) { Update_soflan(); return; }，原逻辑整体保留为非 soflan 路。Update_soflan() 关掉 fadeInAnimator，按 §一分段驱动淡入/待机/移动，视觉部分不含任何 DestroySelf/Skip/Running。

5

UpdateStar() 一分为二 Q12

UpdateStarVisual(process) 只做位置插值 + 切线朝向 + alpha/scale；UpdateStarLogic() 用真实时间 process 保留 Enable/Random 的销毁、跳队列、smoothSlideAnime 的 HideBar。soflan 路每帧照常调 Logic（真实时间）。

6

HideBar 单调保护 + Running 用逻辑位置 Q3/Q6

HideBar 见 §二代码。Running() 不读 transform.position，改读 GetLogicStarPos()（真实 process 插值），DJAuto 触发时刻与真实时间一致。

五、连续星星（Slide Group）

如 1-2[4:1]s3[4:1]，交棒逻辑天然由 alpha 判据处理：

  • 视觉交棒吃 soflan：非头段进度未进自己移动窗口时 alpha=0，进了才亮；soflan 倒退跨段边界时前段星星能重新亮（回吐）。
  • 不提前销毁：DestroySelf / OnDestroy / ForceFinish 全维持真实时间，整组延到真实末尾 + 组尾判定完成再一次性 Destroy。代价是各段 GameObject 要活到真实末尾（多几个隐藏对象）。
